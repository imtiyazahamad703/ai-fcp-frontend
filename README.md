# AI Fullstack Coding Platform (Frontend)

Welcome to the **AI Fullstack Coding Platform** frontend client, built by **Imtiyaz Ahamad**. This highly interactive, fully responsive frontend provides a state-of-the-art coding environment for learners and a powerful dashboard for administrators.

## Core Technologies
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 (with Global Dark/Light themes)
- **State Management:** Zustand
- **Code Editor:** Monaco Editor
- **Live Preview:** Sandpack (in-browser React execution)

## Key Features
- **Dual-Screen Mobile IDE:** A beautifully polished mobile UI with floating action bars, problem tabs, and responsive editor tools.
- **Floating AI Chatbot:** An interactive, draggable AI "Workspace Buddy" to assist learners with code explanations.
- **Admin Dashboard:** Fully responsive data grids, Monaco review editor, and 1-click AI generation controls.
- **Interactive Scratchpad:** A markdown-supported notepad that syncs directly with the database.

## Scripts

```bash
# Install dependencies
npm install

# Run the frontend in development mode
npm run dev

# Build for production
npm run build
```
